# Asset licence notices

These notices were saved with the reviewed downloads on **2026-09-07**. The exact
notice file bytes, source repositories/revisions, and SHA-256 hashes are locked in
`assets/manifest.json`. Preserve the original files: do not reformat their line
endings or replace them with a generic licence. `.gitattributes` prevents automatic
line-ending conversion of checksum-locked source assets/notices.

- `adventurers.txt`, `skeletons.txt`, `dungeon.txt`: Kay Lousberg's original CC0
  notices from the creator's KayKit repositories.
- `kenney-interface.txt`, `kenney-particles.txt`, `kenney-icons.txt`, `kenney-ui.txt`,
  `kenney-board-icons.txt`: Kenney's original CC0 notices preserved by the reviewed
  redistributors. The particle notice includes its filter-template contributors.
- `kenney-impact.txt`, `kenney-rpg.txt`: full **CC0 1.0 Universal legal code** supplied
  by the corresponding Godot redistributions. Kenney's original pages independently
  confirm CC0 for those exact packs.
- `boss-music.txt`: upstream redistribution notice naming the track, CC0, and its
  original OpenGameArt page. The creator's page displays **License(s): CC0** for
  **Juhani Junkala / SubspaceAudio — Epic Boss Battle [Seamlessly Looping]**:
  https://opengameart.org/content/boss-battle-music
- `menu-music.txt`: upstream **credits**, not a newly authored licence grant. Its
  link identifies **RandomMind — Medieval: The Old Tower Inn**. The original page
  displays **License(s): CC0** and the creator states: “My CC0 track available in
  full and loop version, you can freely use for any purpose!” The other tracks
  mentioned in that preserved credits file are **not included** here:
  https://opengameart.org/content/medieval-the-old-tower-inn
- `rajdhani.txt`: Indian Type Foundry copyright and the complete **SIL Open Font
  License 1.1**, downloaded alongside the unmodified Regular and Bold TTFs from
  Google Fonts. Keep this notice with redistributed copies; fonts cannot be sold
  by themselves and modified versions remain subject to OFL naming conditions.

Full CC0 terms: https://creativecommons.org/publicdomain/zero/1.0/legalcode
(an offline copy is included in `kenney-impact.txt` and `kenney-rpg.txt`).

The Android export presets explicitly include this folder's `.txt` / `.md` notices
and both provenance manifests. Asset authors are credited voluntarily for CC0;
font licence/copyright retention is mandatory. No third-party game code or plugins
were taken from the asset redistribution repositories.
